# Bihu_project_2
Research work


HTML figures T1-T4 provide 3 dimensional plots of predicted Fecal Coliform Pollution States (1,2 and 3) against observed values of the 3 variables with highest VI values. Snapshots of each of these images are provided in Figure 5 of the manuscript.

T1.html: Plots for (major) rivers, i.e., Type 1 water bodies Figure 5 (a)
T2.html: Plots for medium and minor rivers, i.e., Type 2 water bodies Figure 5 (b)
T3.html: Plots for lentic water bodies, i.e., Type 3 water bodies Figure 5 (c)
T4.html: Plots for canals, i.e., Type 4 water bodies Figure 5 (d)
